How It Works · Delivered

Control plane + data plane, cleanly separated

⚙️ Control Plane · api-server (Go)

  • Connector registry (REST register / update / deregister)
  • Capability discovery & manifest descriptor
  • Secret references, RBAC, rate-limit gate
  • Audit log & versioned DB migrations
  • Mellea translate + batch query coordination

📡 Data Plane · connector-runtime (Go)

  • Generic manifest-driven HTTP engine
  • Pagination, retries, circuit breakers
  • Pluggable auth strategies
  • Normalization + source payload
  • Redis cache & per-connector rate limits

Delivered · Manifest-Driven Connectors

Add a connector by writing YAML, not Go

displayName: Snowflake  # connectors/snowflake/manifest.yaml (abridged)
version: "1.0.0"
baseUrl: https://{account}.snowflakecomputing.com  # templated + allowedHostSuffixes guard
authentication:
  methods: [key_pair, oauth, pat]  # picked from the credentials supplied
resources: { statements: { operations: { create: …, get: … } } }
normalization: { fieldMappings: … }  # declarative → canonical envelope
contractTests: { fixtures: … }  # run via ./scripts/run-contract-tests.sh

Delivered · Developer Surfaces

Same contract from the terminal, code, and browser

⌨️

CLI — odb 0.2.0

connect · get · batch · describe · capabilities. Credentials and prompts are built from the connector descriptor.

🐍

Python SDK 0.2.0

Sync and async clients, Pydantic models, dynamic client.<name>.<resource>.<op>() for any manifest operation.

📜

JavaScript / TypeScript SDK 0.2.0

Typed client with a dynamic connector proxy; client.describe(name); API key optional in non-prod.

🖥️

Dev Explorer UI (Next.js)

Forms and actions rendered from manifests (Carbon). Sync manifests button, write-action confirmation, Mellea tab, multi-source tab.

Everything above is fed by one endpoint: GET /v1/connectors/{name}/manifest — a display-safe descriptor. Change the manifest, click Sync, and the UI updates with no code change.

Delivered · Security & Governance

Zero-credential-leak runtime, governed from Day 1

🔑

Secrets providers

Environment and HashiCorp Vault today, with an in-memory resilience cache (ODB_SECRETS_CACHE_TTL) for vault blips

👤

RBAC bound to key

Role is bound to the API key server-side (ODB_API_KEY_ROLES). Client role headers are ignored by default

🙈

Field-level masking

Manifest maskFields and sensitivity tiers redact data as [REDACTED]

📝

Audit trail

PostgreSQL audit log: caller, duration, status, params — never credentials, never fails the call

🚦

Rate limits

Per-capability limits enforced; rate_limited audit path live; Redis-backed counters

🧱

Safe HTTP executor

Same-origin pagination, host allow-lists, no retry on POST / PATCH, 403 → permission_denied

🗄️

Versioned migrations

golang-migrate on startup, with guarded rollback

📐

Spec-driven

OpenAPI 3.1 + manifest schema are the contract; contract tests in CI
